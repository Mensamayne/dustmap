# dustmap-same-meaning

Published Dustmap embedding package (REL-06). Install:

```bash
dustmap model pull dustmap-same-meaning
```

Source: [Mensamayne/dustmap-models](https://huggingface.co/Mensamayne/dustmap-models) (`dustmap-same-meaning/`).

| | |
|---|---|
| Role | Same-meaning layer: every function → a vector |
| Licence | MIT |
| Base | `microsoft/unixcoder-base` (Apache-2.0) |
| Variants | CPU (weight-only int8 ONNX), GPU (fp16 ONNX) |
| Default in Dustmap | `semantic.model` |

Formerly the maintainer-local `dustmap-same-meaning-private` (EMB-15). Published under MIT by decision of 26.10.2026: open weights, no fee.
